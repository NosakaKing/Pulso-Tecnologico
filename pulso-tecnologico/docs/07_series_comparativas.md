# 07_series_comparativas — Series temporales comparativas

## Objetivo

Comparar series temporales de varias tecnologías para identificar co-movimientos, sustituciones y patrones estacionales o cíclicos.

## Pasos

1. Seleccionar un conjunto de tags a comparar.
2. Alinear series por fecha y normalizar (p. ej. índice base 100 en un año de referencia).
3. Visualizar comparativas con subplots o gráficos interactivos.
4. Analizar correlaciones y posibles causalidades (correlación cruzada, lag analysis).

## Reproducir

```bash
jupyter nbconvert --to notebook --execute fase_3_analisis/07_series_comparativas.ipynb
```

## Relevancia para la tesis

Permite mostrar ejemplos concretos donde dos tecnologías siguen trayectorias similares (p.ej. frameworks que comparten ecosistema) o se reemplazan mutuamente.
