# 08_cruce_survey_mercado — Cruce encuesta vs mercado vs SO

## Objetivo

Cruzar las señales de Stack Overflow (volumen, crecimiento) con la evidencia de mercado (ofertas, reportes regionales) y la encuesta de desarrolladores para generar un score combinado que respalde recomendaciones curriculares.

## Pasos

1. Normalizar y alinear las fuentes por tag y periodo.
2. Calcular métricas compuestas (por ejemplo: `composite_score = alpha*growth + beta*used_pct + gamma*market_demand`).
3. Rankear tecnologías y extraer Top-N por categoría.
4. Exportar recomendaciones y tablas de soporte.

## Relevancia

Provee la justificación multifuente necesaria para defender cambios curriculares en la tesis.
